# Utility Belt Features

## Document Tools
- **DOCX to PDF**: Convert Word documents to PDF format
- **PDF Tools**: Split, merge, and compress PDFs
- **File Compressor**: Compress various file types
- **Text Extractor**: Extract text from images using OCR technology
- **File Format Checker**: Check and validate file formats

## Image Tools
- **Image Resizer**: Resize images and adjust file size
- **Image Converter**: Convert between different image formats

## Conversion Tools
- **Length Converter**: Convert between different units of length
- **Weight Converter**: Convert between different units of weight
- **Time Converter**: Convert between different time zones
- **Temperature Converter**: Convert between different temperature units
- **Speed Converter**: Convert between different speed units
- **Area Converter**: Convert between different area units
- **Volume Converter**: Convert between different volume units
- **Unit Calculator**: Calculate and convert various units
- **Base64 Converter**: Encode and decode Base64
- **Color Converter**: Convert between color formats

## Data Format Converters
- **JSON Formatter**: Format and validate JSON data
- **JSON to Excel**: Convert JSON data to Excel format
- **Excel to JSON**: Convert Excel files to JSON format
- **CSV to JSON**: Convert CSV files to JSON format
- **JSON to CSV**: Convert JSON data to CSV format
- **XML to JSON**: Convert XML data to JSON format
- **JSON to XML**: Convert JSON data to XML format
- **YAML to JSON**: Convert YAML data to JSON format
- **JSON to YAML**: Convert JSON data to YAML format

## Health & Fitness Calculators
- **BMI Calculator**: Calculate your Body Mass Index
- **Body Fat Calculator**: Calculate your body fat percentage using the U.S. Navy method
- **Body Surface Area Calculator**: Calculate your body surface area using multiple formulas
- **TDEE Calculator**: Calculate your Total Daily Energy Expenditure
- **Calorie Calculator**: Calculate your daily calorie needs
- **Ideal Weight Calculator**: Calculate your ideal weight using multiple formulas

## Security Tools
- **Password Generator**: Generate secure passwords with customizable options

## Features
- Modern, responsive UI with animations
- Real-time calculations and conversions
- Input validation and error handling
- Helpful information and tooltips
- Mobile-friendly design
- Secure file processing
- No file storage (all processing done locally)

## Technical Details
- Maximum file size: 10MB per file
- Supported image formats: PNG, JPEG, GIF, WebP, AVIF, TIFF
- Supported document formats: DOCX, PDF
- Supported data formats: JSON, CSV, XML, YAML, Excel
- All calculations are performed client-side for privacy and speed

## Getting Started
1. Navigate to the desired tool from the home page
2. Input your data or upload your file
3. Configure any additional options
4. View or download your results

## Privacy & Security
- All file processing is done locally in your browser
- No files are stored on our servers
- No personal data is collected or stored
- Secure HTTPS connection for all communications
